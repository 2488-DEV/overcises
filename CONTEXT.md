# Overcise

A gamified exercise app for teens and working adults. Users exercise on camera, earn points, climb a ranking, and redeem rewards from partner shops.

## Language

**Valid Rep**:
One repetition of an exercise that the camera AI judges to have correct form. Only Valid Reps earn Points.
_Avoid_: Rep (unqualified), count

**Points**:
The score a user earns from Valid Reps and completed Quests.
_Avoid_: Score, XP, coins

**Ranking**:
The monthly leaderboard ordering users by Points. Top-ranked users (the sheet says rank ≤ 20) win a Reward.
_Avoid_: Leaderboard, scoreboard

**Quest**:
A mission the user can complete for Points.
_Avoid_: Task, challenge, mission

**Reward**:
A discount or perk from a partner shop (food or fitness), given to top-ranked users at month end.
_Avoid_: Prize, coupon

**Guide**:
The feature that shows users which exercise to do and how to do it.
_Avoid_: Tutorial, coach
